# HotFoto AI V48.2 — Client Proofing & Photographer Review

## What changed
V48.2 completes the first two-way client workflow after private delivery.

### Client
- Favorite frames.
- Select final frames.
- Comment on individual frames.
- Submit proof once.
- Submitted proof becomes read-only from the public proof link.

### Photographer
- Delivery history exposes proof status.
- Review proof shows selected frames, favorites, comments and client name.
- Copy delivery links directly from Delivery history.

### Backend
- `hotfoto_proof_actions` persistence table.
- Delivery proof status and submission metadata.
- Public token-scoped proof endpoints.
- Authenticated owner proof review endpoint.
- Local fallback mirrors the PostgreSQL contract.

## Product boundary
Client feedback is a signal to the photographer's production workflow. It never mutates an original master or silently changes an AI-generated rendition.
